## Rulings (owner decisions, numbered, carried across revisions)
R1–R198 carry as last written, except R82 (withdrawn) and R145, R146 (superseded).
R199 **Cloud pilot findings (planner, from the session report of 2026-10-15).** (a) The cloud's GitHub proxy serves only the session's own repository, so Composer's zip downloads from `api.github.com` get 403 for every dependency; `composer install --prefer-source` (git clones) works for 195 of 196 packages. (b) `phpstan/phpstan` is the one package with no git source in `composer.lock` (dist-only zipball), so it cannot be installed in the cloud at all without a hand-built cache entry. (c) Composer refuses plugins as root unless `COMPOSER_ALLOW_SUPERUSER=1`; without them Pest's `--parallel` is missing. (d) The Wayfinder route modules under `resources/js/wayfinder/` are git-ignored generated files and must be generated (`php artisan wayfinder:generate --with-form`) before `vue-tsc` and the build. (e) `npm run build` fails because the `laravel-vite-plugin/fonts` Bunny plugin fetches `fonts.bunny.net` at build time and the environment's allow-list did not include it; without the build, `public/build/manifest.json` is missing and every Inertia page test fails (551 of 2602). (f) Under the parallel run on PostgreSQL 16, 33 foreign-key violations on `tutor_profiles.user_id` and 3 "password authentication failed for user postgres" appeared and did not reproduce serially — unconfirmed, to be re-read after (e) is fixed. (g) `/ops/status` answered 200 with the token from the environment; the token was never printed.
R200 **16a — portable tooling (fixes a, b, c, d).** (1) PHPStan leaves Composer: remove `phpstan/phpstan` (and any `phpstan/*` extension that depends on it only through the phar) from `require-dev`; add `tools/phpstan.phar` **not** committed but fetched by a tiny script `scripts/fetch-phpstan.sh` from `https://raw.githubusercontent.com/phpstan/phpstan/<pinned tag>/phpstan.phar` (raw.githubusercontent.com is on the cloud's default allow-list and serves committed files of public repos), verified against a pinned SHA-256 committed in `scripts/phpstan.sha256`; `composer test`, CI and the Herd local flow call `tools/phpstan.phar` (the script is run by `composer install`'s `post-install-cmd`, by CI, and by the cloud setup script); `phpstan.neon` unchanged. If the project uses PHPStan extensions that must be Composer packages, keep those and confirm each has a git source in the lock (`composer show -t` plus a test in `tests/Unit/ComposerLockPortabilityTest.php` that fails if any locked package lacks `source`). (2) `composer.json` `config.preferred-install` set to `source` for the cloud only via `COMPOSER_PREFER_SOURCE`-style env is not a Composer feature, so instead: the cloud setup script runs `composer config -g preferred-install source` before `composer install`; CI and local keep dist. (3) `wayfinder:generate --with-form` added to `composer.json`'s `post-autoload-dump` (idempotent, writes only git-ignored files) so every install produces the route modules; `npm run types:check` and `npm run build` then work without a manual step. (4) `COMPOSER_ALLOW_SUPERUSER=1` documented in `docs/cloud/ENVIRONMENT.md` as an environment variable (the planner adds it). ADR-028.
R201 **16b — cloud build (fixes e, f).** (1) The Bunny fonts plugin must not break a build without network: wrap it so that when `fonts.bunny.net` is unreachable the build still succeeds with the fonts referenced by URL instead of self-hosted (the plugin's own fallback if it has one; otherwise an env flag `VITE_FONTS_INLINE=0` that skips the plugin), with the self-hosted path unchanged for CI, local and rehearsal; the planner also adds `fonts.bunny.net` to the environment allow-list so the normal path works too. (2) After (1), re-run the full suite on PostgreSQL 16 in CI (already in the matrix) **in parallel mode** and locally against a PG 16 container if available; if the 33 FK violations or the 3 auth failures reproduce, fix the cause (most likely parallel test databases being created without the role password, or a factory ordering issue) with a test; if they do not reproduce on PG 16 in CI, record that in STATUS §6 as "cloud-load artefact, re-read on the next pilot". ADR-028 addendum.
