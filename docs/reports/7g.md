# 7g — Branding (R49)

Cycle 07 r1, step 8, branch `cp/7g-branding`. Scope: palette, type, radii and lockups from `docs/brand/` on the front end and the Filament admin theme. No layout or copy changes.

## What changed

| Area | Change |
|---|---|
| Tokens | `resources/css/app.css`: the designer's `--tt-*` values verbatim; the shadcn tokens (`--primary`, `--background`, `--border`, …) are mapped onto them, so every existing component takes the palette without a per-component edit. Primary `#64011D`, page ground `#FBF8F7`, ring `#8A0A2A`. |
| Radii | `--radius-md`/`-lg` = 10px (buttons, fields), `--radius-xl` = 16px (cards). Admin: 8px controls, 12px cards. |
| Type | Schibsted Grotesk (400/500/700) for UI, Quicksand 600 for the tagline only, IBM Plex Mono for data. All three are self-hosted by the Vite fonts build (`vite.config.ts`), and the Filament panel loads the same files (no runtime CDN). |
| Lockups | New `BrandLockup.vue` (lockup / wordmark / symbol; follows the colour scheme, `dark` forces the white knockout, `decorative` blanks the alt). Used in the public header, the app sidebar (wordmark, symbol when collapsed) and the three auth layouts. |
| Tagline rule | "Tutoring, Electrified." sits beside the wordmark from 768px, drops below (start-aligned, no rule) under 768px and is dropped under 480px. |
| Head | Favicons 16/32, apple-touch icon 180, `og:image` 1200×630, inline first-paint background `#FBF8F7`. |
| Admin | `resources/css/filament/admin/theme.css` (Vite input): sidebar `#240A12`, active item 14% coral tint with a 3px coral bar, canvas `#F6F5F6`, 8/12 radii. `AdminPanelProvider`: explicit maroon ramp (600 = `#64011D`, 500 = `#8A0A2A`), brand name, wordmark logo, favicon, font. |
| Removed | `public/favicon.svg`, `AppLogoIcon.vue` (unused after the swap). |

## Disclosures

- **Raster only.** The pack ships PNGs; nothing is scaled above its supplied size (the wordmark uses a 600/1200 `srcset`). The vector redraw, tagline outlines and heavier symbol cut are outstanding from the designer (CP8).
- **`public/favicon.ico`** now contains the brand 32 px PNG bytes under an `.ico` name (browsers sniff the content; no ICO encoder was available). The `<link>` tags point at the PNGs. Replace with a real `.ico` when the designer supplies one.
- **No dark palette in the pack.** The `.dark` scheme in `app.css` is derived from the same maroon and coral on the darkest ground and is marked as such in a comment. The default appearance is `system`, so a dark OS does get it. In it the marks swap to the white knockout (`BrandLockup` follows the scheme; the admin uses `darkModeBrandLogo`), and the primary is the lighter coral-400 (about 7:1 on the dark ground), so `text-primary` links are coral there. That is the one place coral is text; it is outside the pack's coral rule (which exists because coral is 3.4:1 on white) and is flagged for the designer.
- **Coral** in the light scheme appears only as the admin active bar/tint and as part of the logo artwork; never as text. See the dark-scheme note above for the exception.
- **Filament's `Color::hex('#64011D')`** lightens the seed to a pink (its 600 shade was `oklch(0.60 …)`), so the panel uses an explicit ramp instead.
- **Site name text** (the `site_name` setting) is no longer rendered in the public header and sidebar; the brand wordmark replaces it (alt text "TrusTutor").
- **Untouched by design:** starter-kit sidebar footer links (Repository, Documentation), Filament's default Welcome/Info widgets, copy, layouts.
- **`logo_path` / `favicon_path` site settings** (CP1, `config/settings.php`, upload fields in `ManageSettings`) exist but nothing in the app reads them, before or after this step; the brand assets are fixed files under `public/brand`. Wiring the settings to the layout is out of scope for a token/lockup pass and is listed under Deferred in STATUS.md.
- The UI developer's review of this step is non-blocking (R123).
